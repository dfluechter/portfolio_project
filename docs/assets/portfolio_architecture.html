06 — DNS & SSL Konfiguration
ipv64.net DNS RECORDS
dfluechter.ipv64.de CNAME portfolio-project.onrender.com
dfluechter.ipv64.de A nur falls CNAME nicht möglich
✅ CNAME ist bevorzugt — Render's IP kann sich ändern
✅ Let's Encrypt via Render — keine manuelle Erneuerung
✅ HTTPS automatisch nach Domain-Verifizierung (~2-5 Min)
⚠️ Bei Root-Domain (@) muss A-Record gesetzt werden
SSL FLOW
1️⃣ CNAME setzen bei ipv64 dfluechter.ipv64.de → *.onrender.com
2️⃣ Custom Domain in Render eintragen Dashboard → Settings → Custom Domains
3️⃣ Render verifiziert DNS HTTP-01 ACME Challenge automatisch
🔒 Zertifikat ausgestellt & aktiv Auto-Renewal alle 60 Tage · kein Aufwand
