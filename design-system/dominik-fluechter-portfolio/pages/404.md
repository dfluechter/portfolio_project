# Page Specification: 404 Error State (Route Not Resolved)

> **LOGIC:** This specification defines the layout, visual hierarchy, tokens, and interactions for `NotFoundPage.tsx` (`path="*"`).
> Governed by `design-system/dominik-fluechter-portfolio/MASTER.md`.

---

## 1. Context & Purpose

- **Primary Goal:** Inform the user when accessing an invalid or decommissioned route, explain the reason gracefully in the technical Swiss/Systems Architecture aesthetic, and provide fast, friction-free paths back to the application modules.
- **Aesthetic Direction:** Swiss Style Minimalist Architecture meets High-Tech Systems Monitoring (`SYS // 404: ROUTE_NOT_RESOLVED`).
- **Tone:** Informative, technical, calm, professional.

## 4. Accessibility (WCAG 2.2 AA)

1. **Heading Hierarchy:** `<h1>` for primary title *"Zieladresse nicht auffindbar"*, logical sections below.
2. **Keyboard Navigation:** Sequential Tab-Index across Home Button, Back Button, and Quick-Links.
3. **Focus States:** 2px visible Indigo-500 ring with 2px offset (`focus-visible:ring-2 focus-visible:ring-indigo-500`).
4. **Color Independence:** Error status communicated via icon (`ShieldAlert`), text, and color simultaneously.
